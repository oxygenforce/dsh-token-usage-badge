# dsh-token-usage-badge

每条回答的下方，一行淡色读数：**本轮 Token** · **回答耗时** · **本会话累计 Token**。

![预览](assets/preview.png)

```
[复制] [赞/踩] [分支] [↗]    20:10   1.1M tok · 1分02秒 · 共 26.9M tok
```

从左到右每一段：

| 片段 | 含义 |
| --- | --- |
| `20:10` | 官方结束时间（宿主自带，非本插件） |
| `1.1M tok` | 本轮 Token：这一次提问→回答的消耗 |
| `1分02秒` | 回答耗时：提问→回答落盘的墙钟时间 |
| `共 26.9M tok` | 本会话累计 Token |

- **数据来源**：本轮读数取自宿主的 `turn-tail` 节点，与官方「用量」弹窗同一口径；会话累计读 `tokenUsage` 投影，实时更新。
- **常驻可见**：官方动作行只在最后一条回答上常显，历史回答要悬停才出现；本插件仅对含读数的行解除该限制。
- **精确分解**：鼠标悬停读数，可看到未缓存输入 / 缓存读取 / 缓存写入 / 输出 / 其中推理的精确数字。
- **生成中可见**：回答还在生成时，「深度求索中，用时 …」那行紧跟耗时之后会显示 `+12.3K tok`，`+` 后面的数字就是**这一个回答**到目前为止的消耗（不含历史回合）。数字每完成一个步骤刷新一次，是真实用量，不按字符估算。

## 安装

**方式一：插件市场（推荐）**

插件收录到 DSH 插件市场后，在 Harness 里打开「插件市场」搜索 `dsh-token-usage-badge` 即可一键安装。

**方式二：本地目录 / Release 包**

1. 打开 [Releases](https://github.com/oxygenforce/dsh-token-usage-badge/releases/latest) 页面，下载最新一版的 `dsh-token-usage-badge-<版本>.tgz` 并解压（内部是 `package/` 目录）；
2. 在 Harness 的插件管理页选择「从本地目录安装」，指向解压出来的 `package/` 目录；
3. 安装后刷新一次 Web 页面，读数即刻出现，不需要重启 `dsh web`。

> 本包同时带有 `dsh.bundle.patch` 与 `cordis.patch.yml`，两条安装路径都会按 bundle 正常启用。

## 兼容性

- 面向 `@deepseek-ai/dsh-client-ui-chat` / `dsh-client-ui-conversation` 的 `0.2.1-rc.2` 客户端契约（`conversation.chat.turnTail` 槽位、`turn-tail` 节点数据）。
- 纯客户端插件：Host 半边只做日志占位，不注册任何服务、不读写文件、不发网络请求。
- 所有样式都走 `--dsw-alias-*` 主题令牌，深浅色自动跟随；只注入一个 `<style>` 标签、一个读数槽位条目，以及一个渲染 `null` 的隐形投影探针。

## 实现要点

**位置**

- 注册在 `conversation.chat.turnTail`（`order: -10`），用 `react-dom` 的 portal 把读数接到官方动作行结束时间之后；取不到动作行时原地降级渲染。
- 分隔线由 `centerRule()` 实测「正文底边 → 线 → 动作行顶边」，再用 `transform: translateY()` 做视觉微调；不改 margin，避免流式渲染时触发滚动锚定跳动。

**外观**

- 字体与颜色全部走 `--dsw-alias-*` / `--dsh-content-*` 令牌，深浅色自动跟随；只注入一个 `<style>` 标签。
- 官方动作行默认只在最后一条回答上常显，历史回答要悬停才出现；本插件仅对含读数的行解除这条限制。

**只渲染一份**

- `enforceSingleRenderer()` 给本实例节点打上 `data-dtc-owner`，同一动作行里其余读数与分隔线隐藏（不删 DOM，避免打断宿主的 React 重渲染）。改名、热更新、多窗口并存都不会叠出第二份。
- `tidyRunningStatus()` 清理旧版行内 chip 的残留样式，并把「深度求索中，用时…」那行改成文字在前、细线在后。

**数据**

- 本轮读数取自宿主 `turn-tail` 节点里的 `TurnTokenUsage`，耗时取 `turn.start.time` → `closing.time`，与官方「用量」弹窗同一口径。
- 会话累计读 `tokenUsage` 投影，把未缓存输入 / 缓存读取 / 缓存写入 / 输出相加，随新回合实时增长。
- 生成中的实时数字用同一投影对「本回合起点」取增量（换轮自动重置起点，起点未知时宁可不显示，绝不拿会话累计冒充本轮）；宿主每落盘一个步骤才更新一次，所以它是每步刷新的真实值，不是估算曲线。每个「进行中的回合」各自存档起点：切换对话再切回来，读数当帧恢复，不用等下一次落盘。
- 官方设置「性能与用量」的 pill 已经显示本轮 token 时，本插件只补耗时和会话累计，不在同一行重复同一个数字；那颗 pill 关掉时自动补回。
- 第一步还没结算时宿主没有任何用量可读，此时先按已流出的文字量给出带 `~` 的估算（例如 `~1.4K tok`），结算上报后立刻换成不带 `~` 的精确值。

**失败策略**

- 组件内部 `try/catch`，任何异常都返回 `null`，绝不连累对话界面。
